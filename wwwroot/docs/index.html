FacilApp SQL API

API HTTP para autenticação OAuth2, acesso multibanco, SQL, configurações e integrações fiscais. Esta página é gerada a partir do contrato OpenAPI publicado pela própria API.

Endereço oficial

https://sql.facilapp.com.br

Use HTTPS em aplicações web e integrações externas. Nunca publique Client Secret, senha ou Bearer em código-fonte, páginas HTML ou logs.

Autenticação

OAuth2 padrão

Envie grant_type=client_credentials, client_id e client_secret para /oauth/token.

Client e Secret em JSON

Use /oauth/login-simples para integrações web e IAs. A resposta contém Bearer e o contexto da empresa vinculada.

Login da empresa

O login tradicional usa sistema, CNPJ, usuário e senha. A credencial OAuth vinculada é localizada internamente.

curl -X POST https://sql.facilapp.com.br/oauth/login-simples \
  -H "Content-Type: application/json" \
  -d '{"client_id":"SEU_CLIENT_ID","client_secret":"SEU_CLIENT_SECRET"}'

Usando o Bearer

curl https://sql.facilapp.com.br/ROTA \
  -H "Authorization: Bearer SEU_ACCESS_TOKEN"

As permissões efetivas do token vêm da credencial: por exemplo sqlserver, configuracao, nfe e nfce.
