# FacilApp SQL API

Fonte público da API FacilApp SQL, do Swagger, das telas web e dos SDKs C# e Python.

## Conteúdo da publicação

Esta cópia inclui os bancos SQLite neutros de estrutura da API (`Dados/facilapp_sql.db`) e do Curso (`BasesSQLite/CURSO.db`). Não inclui arquivos INI, certificados, chaves, segredos, backups nem binários de compilação. Configure o ambiente local antes de executar a API.

## Suporte ao código-fonte

A compra do curso não inclui suporte técnico ao código-fonte. O material é disponibilizado para estudo e uso conforme as orientações do curso.
